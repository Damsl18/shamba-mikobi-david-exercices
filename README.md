# shamba-mikobi-david-exercices
Le repository contient les réponses du travail donné dans la Masterclass Cyberdev qui concerne le module 1 et 2
**CONTENU DU PROJET**
Ce projet contient les résolutions des exercices données dans la masterclass Cyberdev afin de mettre en pratique les leçons apprises lors du module 1 et 2 de la masterclass.
il est constitué de 5 dossiers qui sont:
1. **AWS**: qui contient la resolution des questions concernant le cloud
2. **BASH**: qui contient les différents scripts bash demandés
3. **LINUX**: qui contient les commandes linux demandées ainsi que leur sorties et explications
4. **PACKET-TRACER**: qui contient les différentes topologies de reseau demandées 
5. **PYTHON**: qui contient tout les scrips python demandés
